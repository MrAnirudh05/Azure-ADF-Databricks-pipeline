# 🚀 Azure Data Factory + Databricks End-to-End Pipeline

## 📌 Overview
This project demonstrates a complete end-to-end data pipeline using Azure Data Factory and Databricks, including ingestion, transformation, storage, and logging.

## 🏗 Architecture
![Architecture](architecture/your-image-name.png)

---

## 🔄 Pipeline Flow
1. Set ingestion time
2. Fetch data from API
3. Store data in ADLS (Raw Layer)
4. Transform data using Databricks
5. Store data in Curated Layer
6. Log Success / Failure
